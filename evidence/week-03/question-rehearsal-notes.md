# Week 03 - Question Rehearsal Notes

> This is **not** final stakeholder evidence. It records how the team improved questions before Week 04 simulation.  
> ไฟล์นี้เป็นการซ้อมกับเพื่อนในทีม (ไม่บังคับ) สำหรับคำถามของบทบาทที่ไม่ได้ใช้ AI — การซ้อมกับ AI ตาม contract อยู่ที่ [`ai-interview-rehearsal-notes.md`](ai-interview-rehearsal-notes.md)

## Participants and Roles
| Name | Role | Contribution |
|---|---|---|
| ปวีณา | Interviewer | ถามคำถาม Q-10 (บทบาท IT) ตาม guide |
| ชลิตา | Stakeholder proxy — ผู้ดูแลระบบ IT | ตอบตาม profile IT ใน `docs/02` §1.1 |
| ณัฐพล | Note-taker | บันทึก wording, follow-up และสิ่งที่ยังไม่ชัด |
| วรินทร์ | Quality observer | จับคำถามชี้นำและตรวจว่าคำถามเชื่อม EO หรือไม่ |

## Rehearsal Summary
- Questions tested: Q-10 (บัญชีสถาบันและข้อมูลที่ไม่ควรเก็บซ้ำ — EO-06 / A-03)
- Questions that were unclear / leading: IT proxy ตอบเชิงเทคนิคเร็วเกินไป ทำให้ interviewer อาจไม่เข้าใจผลกระทบต่อ role/data
- Follow-up questions added: "ข้อมูลนั้นจะช่วยให้ระบบตัดสินใจเรื่องใด และข้อมูลใดไม่จำเป็น?"
- Changes made to the interview guide: เพิ่ม follow-up ใน Q-10 (`docs/03-interview-guide.md` §2)
- Evidence rules to use in Week 04: ใช้ E-ID เรียงลำดับ ระบุบทบาท/session และ type ทุกครั้ง (ดูท้าย `ai-interview-rehearsal-notes.md`)
