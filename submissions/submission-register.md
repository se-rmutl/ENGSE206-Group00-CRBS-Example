> **Commit ฉบับส่ง** คือ commit `submit(wNN)` ที่ลิงก์ permalink ชี้ · ในใบส่งงานแต่ละฉบับ ช่อง Submission commit hash คือ commit งานล่าสุดก่อนส่ง (parent ของ commit ส่ง)

**สถานะที่ใช้:** `ส่งแล้ว` · `ส่งบางส่วน` (เขียนในหมายเหตุว่าขาดอะไร) · `ส่งทางอื่น` (ใส่ลิงก์ในหมายเหตุ เช่น Teams) · `ไม่ได้ส่ง` · `แก้หลังกำหนด` (ใส่ทั้ง commit ฉบับที่ส่งตรงเวลาและ commit ฉบับแก้)

## กติกา

1. **ฉบับที่ตรวจ** — ผู้สอนตรวจตาม commit ในช่อง "Commit ฉบับส่ง" ถ้าว่าง ผู้สอนตรวจตามสภาพ repo ณ วันครบกำหนดของสัปดาห์นั้น
2. **แก้หลังกำหนด** — แก้ได้ แต่ห้ามเขียนทับโดยไม่บันทึก ให้ใส่ทั้งสอง commit ผู้สอนเป็นผู้ตัดสินว่านับฉบับไหน
3. **ไฟล์ผิด path** — ใช้ได้ ถ้าใส่ลิงก์ไฟล์ที่ใช้แทนในช่อง "ไฟล์หลัก" และเขียนเหตุผลในหมายเหตุ
4. **งานที่ทำรวมในสัปดาห์อื่น** (เช่น W10 ที่ทำรวมในเอกสาร W11) — ลิงก์ไปยังหัวข้อนั้นและเขียนในหมายเหตุ
5. **งานที่ส่งนอก repo** — ใส่ลิงก์และวันที่ส่งจริง สถานะ `ส่งทางอื่น`
